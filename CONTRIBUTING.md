# Contributing to the Cemiplimab cSCC Research Project

We welcome contributions to this open-source pharmaceutical intelligence and computational biology repository! Whether you are a computational biologist, clinical researcher, medical writer, or data scientist, your inputs are valuable.

## How to Contribute

### 1. Reporting Issues
*   Use the GitHub Issues tracker to report bugs, document errors, or suggest scientific improvements.
*   Clearly describe the problem, specify which dataset or document is affected, and provide references or citations for scientific corrections.

### 2. Submitting Pull Requests
*   **Fork the repository** and create a feature branch for your changes (e.g., `feature/new-biomarker-data`).
*   **Keep commits logically separated.** Avoid bundling unrelated changes (e.g., mixing formatting changes with clinical trial updates).
*   **reproducible Code:** If you modify or add a Jupyter Notebook, ensure it executes from start to finish without errors in a clean environment.
*   **Write Modular Python Code:** Keep scripts clean and documented.
*   **Do Not Fabricate Data:** All clinical parameters, structural kinetics, and financial figures must match peer-reviewed primary literature.
*   **Citations:** Every scientific statement must have an accompanying inline citation mapping to a reference in `references/references.md` with PMIDs or DOIs.

## Coding Style
*   Markdown files should follow publication-quality standards.
*   Python code should follow PEP 8 standards. Use standard visualization libraries (Matplotlib, Seaborn) with clean, high-resolution formatting.

Thank you for contributing to open-source oncology research!
