# PROJECT.md

# Comprehensive Analysis of Cemiplimab (Libtayo®) for Advanced Cutaneous Squamous Cell Carcinoma (cSCC)

## Project Objective

Develop a comprehensive, open-source pharmaceutical and translational medicine analysis of Cemiplimab (Libtayo®) for advanced cutaneous squamous cell carcinoma (cSCC).

The repository should resemble a hybrid of:
- a pharmaceutical market intelligence report,
- an academic review article,
- a reproducible computational research project,
- and a GitHub portfolio suitable for translational medicine and computational biology.

This project must rely exclusively on publicly available information.

## Core Principles

- Never fabricate data or citations.
- Never speculate without explicitly stating assumptions.
- Prefer primary sources over secondary reviews.
- Every factual statement must be referenced.
- All analyses must be reproducible.
- All code should be documented and executable.

## Workflow

For every new topic:

1. Search authoritative sources.
2. Read and summarize the literature.
3. Extract structured data.
4. Save processed datasets in `/data`.
5. Write reproducible analysis notebooks.
6. Generate publication-quality figures.
7. Write accompanying Markdown documentation.
8. Update README.md.
9. Update TASKS.md.
10. Verify citations.

## Out of Scope

The project will not include:

- Original laboratory experiments
- Patient-level protected data
- Clinical recommendations
- Fabricated analyses
- Proprietary datasets
- Copyrighted figures copied from publications
